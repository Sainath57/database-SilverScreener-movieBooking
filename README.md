**Course**: CSCI 6370 - Database Management  
**Term**: Fall 2023  
**Date**: December 5, 2023  

## Introduction

The project, **SilverScreener**, is a movie ticket reservation platform allowing users to book tickets for various movies. This project incorporates technologies such as **JSP, Servlets, Java, HTML, CSS, JavaScript, Maven Dependencies, MySQL**, and **Apache Tomcat Server** for its implementation.

**Editors**: The project can be executed using **VS Code** or **IntelliJ IDE**, and terminal commands are also available for compiling and saving files.

## Prerequisites

Before running the project, you need to install and configure the following:
- **Java 20**
- **MySQL**
- **Apache Tomcat Server**

### Setup Instructions:
1. **Apache Tomcat Server** module and **MySQL Connector** JAR file must be added to the project.
2. The project consists of `.jsp` files for the front end and `.java` files for the back end.
3. The main entry point of the project is **index.jsp**, which should be executed to launch the application.

## Implementation

The platform allows users to select and book movie tickets. A clear distinction between the **front-end** (handled via **JSP**) and the **back-end** (handled via **Java Servlets**) allows for separation of concerns.

**Key Concepts**:
- **UML Class Diagram**: An initial class diagram was created for the project design, but it turned out to have redundancy issues. The updated version with better database design has been included.
- **BCNF Decomposition and 3NF Synthesis Algorithm**: These database normalization techniques were applied during the project’s design phase to ensure an efficient database structure.

### Changes and Challenges:
Despite excellent work from the team on the front end, the initial backend did not integrate well with the user interface. Due to time constraints, a simplified version of the UI and backend was created to demonstrate the database changes. The original front-end files have also been included as part of the submission to reflect the team's efforts.

## Included Files

- **Main Project Files**: Front-end (JSP, CSS, JS), back-end (Java, Servlets).
- **Initial and Revised UML Class Diagrams**: Shows the progression in database design.
- **BCNF and 3NF Documentation**: Detailed decomposition and synthesis steps.
